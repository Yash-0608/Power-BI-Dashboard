# Sales Performance Dashboard | Power BI

A Power BI dashboard project focused on **visual analytics of a company's sales performance**. The report file is included in this repository so reviewers can open the report and inspect the visuals directly.

## Project at a Glance

- **Focus:** Sales performance reporting and business intelligence
- **Tool:** Microsoft Power BI Desktop
- **Artifact:** `Yash Takalkar Power bi project.pbix`
- **Portfolio relevance:** Power BI Developer, Junior BI Analyst, Reporting Analyst, MIS Executive, and Data Analyst roles

## View the Report

1. Download the [Power BI report file](./Yash%20Takalkar%20Power%20bi%20project.pbix).
2. Open it in [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Review the report pages, visuals, and any available filters.
4. If Power BI requests a data source, follow the prompts to reconnect the source used by the report.

> The PBIX is the primary project artifact. Dataset details, KPI definitions, and screenshots should be added here once documented so reviewers can understand the report without having to open Power BI first.
